## 3. 維持する背骨（不変条件）
原案のうち以下は**そのまま有効**。崩さない。
- 入場/戻りの一本化 `enter()`/`returnToHub()`（タップ・メニュー・〔V2〕対話が同じ処理を呼ぶ）。
- 二重経路（巡る体験＋常時の文字メニュー）。
- V2継ぎ目：`intent+focus` 契約（`types.ts`）、対話UI枠（`AgentSlot`）。
- コンテンツ規約（公開情報のみ・事実創作なし・[サンプル]明示・抽象プレースホルダー・送信なし明示・提案デモ表示）。
- フロント完結 / LLM・backend・送信なし / メモリ状態。
- 軽量モバイル優先 / reduced-motion / 3D失敗時2D継続。
- 演出秒数枠／3場所と各場所固有の入り演出モチーフ（家＝カーテン／風船＝貫通／渦＝吸い込み）。

## 4. 水彩NPR の経緯（試行と学び）
「3Dを動く水彩画に」は本プロジェクト最大の難所。試行錯誤の記録（**同じ轍を踏まないために**）。

**試して分かったこと**
- ❌ **スクリーン後処理だけ**（脱色・階調化・紙ノイズの乗算・vignette）＝“フィルター越し”に見え、動かすと違和感。
  → 学び: スクリーンの膜は世界と一緒に動かないので破綻する。**vignette(画面端の白抜き)はユーザー却下**。
- ❌ **階調化（hard posterize）**＝硬く・暗く「切り絵」化。水彩は smooth な wash＋ムラなので不適。
- ❌ **深度ベースの濡れ縁**＝`@react-three/postprocessing` の DEPTH 属性が depth blit 警告＋不動作。採用せず。
- ❌ **ビルボード（2D絵札）で形を作る**＝横から見ると破綻。ユーザー却下（形は本物の3Dのまま）。
- ✅ **オブジェクト側の水彩マテリアル**（面に絵具が乗る）＝世界が固定なので絵具が面に貼り付き、フィルター感が消える。**これが核心。**
- ✅ **フレネルの濡れ縁**＝深度不要・視点ごとに正しい・黒線でなく顔料だまり。
- ✅ **ヘッドレスChromiumで自分の出力を確認するループ**（§ CLAUDE.md 7）＝盲目的な手探りを解消。**最重要の作業基盤**。

**現状の到達点と限界**
- 面の中の濃淡・紙の白の抜け・濡れ縁・手描き揺らぎは出る。前の「のっぺり単色＋灰色フィルター」からは大きく前進。
- だが依然「様式化された3D」で、手描き水彩画には未到達。**頭打ちの原因はシェーダでなく「形」**（円錐の木・箱の家）。

**結論（方針）**
- 描画（NPR）は自走ループで詰め続ける。
- **次の最大のレバーは「有機的な3Dの形」**（ビルボードでない本物の3Dモデル）。これに水彩描画を乗せると一気に絵に近づく見込み。

## 5. 素材（glTF）パイプライン方針
- 形を有機的にするため、木・家などを**3Dモデル（GLB）**へ。入手：Blender自作 / CC0（Quaternius/Kenney/Poly Pizza）/ ユーザー提供。
- Blender規約：1単位=1m、原点=底面中心、直立、低〜中ポリ、簡素マテリアル（水彩はエンジン側＝`WMat`）、**GLB**書き出し。
- 置き場：`public/models/`。コード：`drei useGLTF` + レジストリ + instancing。
- ⚠️ egress制限で素材DL不可＝**ユーザーがアップロード**して受け渡す。

## 8. ロードマップ（現行）
- **いま**：整理（本コミット）→ 水彩NPRの自走改善 → 形（GLB）導入 → モチーフ/アバター確定 → 仕上げ（可読性・実機・演出）。
- **V2**（原案どおり）：対話エージェント（LLM＋backend）を `enter()` 経由で接続。`intent+focus` と `AgentSlot` を使う。最初からAPIキー認証。
